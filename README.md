# Predicates & Propositional Logic Lair

A super portable, lightly gamified **eLearning web application** for practicing and learning **Propositional Logic** and **First-Order Predicate Logic**.

---

## 📱 Portable & Zero-Prerequisite Execution

This application is **100% self-contained in a single portable HTML file** (`PropNPredsLogicLair.html` or `index.html`).

### How to Run on Any Device (Android, iOS, Windows, Mac, Linux):
1. **No Node.js, No Python, No Server Required!**
2. **On Mobile (Android / iOS)**:
   - Download or receive `PropNPredsLogicLair.html` via WhatsApp, email, or direct download.
   - Tap the file to open it natively in Chrome, Safari, Firefox, or Samsung Internet.
3. **On Desktop (Windows / Mac / Linux)**:
   - Double-click `PropNPredsLogicLair.html` or drag it into any web browser.

---

## 🌟 Key Features

- **70 Built-In Challenges** across 7 difficulty categories:
  1. **Propositional Foundations**: Connectives ($\land, \lor, \neg, \to, \leftrightarrow, \oplus$), truth values, and formula evaluation.
  2. **Equivalence & Laws**: De Morgan's Laws, Implication Elimination, Contrapositive, Distributivity, and Double Negation.
  3. **Tautologies, Contradictions & SAT**: Formula classification, satisfiability tests, and truth table completion.
  4. **Rules of Inference & Proofs**: Modus Ponens, Modus Tollens, Disjunctive Syllogism, Resolution, and deduction proofs.
  5. **Predicates & Quantifiers**: Translating natural language to First-Order Logic ($\forall, \exists$) and quantifier negations.
  6. **Visual Predicate Realm**: Interactive grid world models (Blocks World) where players evaluate or alter shape properties (`Red(x)`, `Square(x)`, `LeftOf(x,y)`) to satisfy quantified logic formulas.
  7. **The Master Logic Lair**: Knights & Knaves riddles, Liar Paradoxes, and Sorites paradox puzzles.

- **Question Assistance Options**:
  - **Submit Answer**: Evaluate your selection or custom logic expression.
  - **Need Hint?**: View a hint explaining the logical principle or rule.
  - **Reveal Answer**: Unveil the exact answer and step-by-step mathematical explanation if stuck.

- **On-Screen Logic Keyboard**: Insert logic symbols ($\land, \lor, \neg, \to, \leftrightarrow, \forall, \exists$) easily on touch devices or desktop.
- **Interactive Sandbox**: Freeplay Truth Table Generator, Formula Equivalence Checker, and Predicate World Sandbox.
- **Local Progress Saving**: XP points, daily streaks, achievement badges, and completed levels save automatically to your browser's local storage (`localStorage`).
